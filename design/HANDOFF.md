# andrey.os — ТЗ на редизайн портфолио

Это пакет для Claude Code. В папке `design/` лежит интерактивный прототип нового портфолио Андрея Дмитриева, сделанный в Claude Design, и всё, что нужно для его реализации. Задача — полностью заменить старый дизайн сайта на этот.

## Свобода решений

**Можно менять что угодно.** Старый код, структуру проекта, фреймворк, библиотеки, сборку. Если удобнее переписать с нуля, переходить на другой фреймворк (Next.js, Astro, SvelteKit, Vite + React и т. д.), добавлять анимационные библиотеки (Framer Motion, GSAP) или менять архитектуру — делай. Единственные жёсткие требования:

- сайт деплоится на Vercel (как сейчас);
- все факты о карьере точно совпадают с CV (`design/Andrey_Dmitriev_CV.pdf`) — даты, должности, цифры, формулировки;
- результат выглядит и ведёт себя как прототип (или лучше), на десктопе и на телефоне;
- производительность и доступность не хуже нормального сайта (Lighthouse 90+, работа с клавиатуры, prefers-reduced-motion).

Прототип — это спецификация поведения и визуала, а не код для копирования.

## Визуальная система

- Фон `#0b0b0c` с точечной сеткой (radial-gradient 1px, шаг 26px), текст `#ecebe6`, приглушённый `#8d8c86`.
- Один акцент: кислотный лайм `#c8ff3d` (в прототипе — настраиваемый). Текст на акценте — `#0b0b0c`.
- Шрифты: **Bricolage Grotesque** (800 для крупных заголовков, плотный трекинг −0.045em) и **JetBrains Mono** (всё остальное). Google Fonts.
- Никаких градиентных «AI»-заливок, эмодзи, Inter/Roboto.
- Лист резюме светлый: `#f7f6f1`, текст `#141413`.

## Экраны десктопа

1. **BIOS-загрузка** (~2.5 c): строки `[ OK ] Loading React modules…` появляются по одной. Любая клавиша/клик — пропуск. Показывается только при первом визите (флаг в localStorage). Перезагрузка — клик по «andrey.os» в меню.
2. **Экран блокировки**: огромные часы, дата, фото в круге, «Click or press any key to unlock». Разблокировка — шторка уезжает вверх.
3. **Рабочий стол**:
   - обои: гигантское «ANDREY» контуром и «DMITRIEV» почти в цвет фона + мигающий лаймовый блок-каретка;
   - верхнее меню: andrey.os (reboot), Portfolio, Resume, Terminal, Contact, ★ Achievements, ⌘K, звук, часы;
   - окно с фото (`andrey.jpg`), слегка повёрнуто, периодически глитчит, перетаскивается; клик открывает about.md;
   - иконки справа: **portfolio.ide** (главная, пульсирует, бейдж «1», кольцо), resume.pdf, github;
   - уведомление «Everything I've built lives in here. Click to open →»;
   - курсор-призрак с плашкой «CLICK ME», который сам летит к иконке IDE (пока пользователь её не тронет);
   - вращающийся стикер «OPEN TO STRONG PRODUCT TEAMS • OPEN TO WORK»;
   - Dock: Terminal, Task Manager, Messages, Now coding, | Trash — с увеличением при наведении;
   - пилюля «★ 3/17 found · see all tricks».
4. **IDE** (открывается анимацией «вырастания» из иконки, рабочий стол размывается):
   - заголовок окна: светофор (закрыть → рабочий стол), строка поиска (открывает палитру ⌘K), кнопка **SUMMARIZE → CV**;
   - activity bar, проводник с файлами: `README.md`, `work/{enterprise-systems, chatbot-and-workflows, senat-ai-platform, ai-character-bot, bitrix-speedup}.md`, `experience.log`, `stack.ts`, `about.md`, `contact.sh`;
   - вкладки с закрытием, хлебные крошки, номера строк, подсветка синтаксиса;
   - README — «главная»: заголовок FULL STACK / DEVELOPER со scramble-анимацией, цифры, бегущая строка со стеком;
   - файлы проектов: frontmatter + огромная метрика + факты; при наведении на строку — «git blame»-подпись;
   - кнопка **▶ RUN** на проектах: в панели терминала построчно печатается мини-демо; для Bitrix — анимированная полоса загрузки 15 s → ~1 s;
   - нижняя панель TERMINAL / PROBLEMS (в Problems: «⚠ candidate not hired yet» + Quick fix → contact.sh);
   - статус-бар акцентного цвета: ветка, ⚠ 1 warning, ★ счётчик, переключатель темы (Andrey Dark / Dracula / Monokai / Solarized Light), язык файла;
   - выделение слова подсвечивает все его повторы в редакторе.
5. **Summarize → резюме**: по IDE проходит луч сканирования («SUMMARIZING 10 FILES → CV»), окно сжимается в белый лист, лист «печатается» построчно из «принтера». Тулбар: ← Back to IDE, Desktop, **EN | RU** (переключение со scramble-эффектом), **Download PDF** (на проде — прямая ссылка на настоящий PDF, а не window.print).

## Окна-приложения (перетаскиваются за заголовок, z-order по клику)

- **Terminal**: команды `help, whoami, ls, projects, skills, contact, neofetch, date, cat <file>, open <ide|cv|github|telegram|taskmgr|messages>, theme <name>, hire andrey, sudo rm -rf boredom, sudo make coffee, konami, sound on|off, clear, exit`. Tab — автодополнение, ↑↓ — история. `hire andrey` — анимация «compiling offer…» и переход в contact.sh.
- **Task Manager**: навыки как процессы (react.exe, nestjs, typescript, fastapi.py, postgres, docker, redis, coffee.service 99%) с живой нагрузкой; клик раскрывает «used in»; End task → шуточный отказ.
- **Messages (Andrey.bot)**: чат с готовыми вопросами. В прототипе ответы по ключевым словам. **Можно сделать на LLM** (API-роут с системным промптом из CV) — на усмотрение, но с защитой от злоупотреблений и fallback на скриптовые ответы.
- **Now coding**: плеер с эквалайзером + кнопка «Listen on Spotify ↗» → https://open.spotify.com/playlist/6qVzdI8XKIji2hjQ5FDy7Y (звука на сайте нет; при желании можно встроить Spotify embed).
- **Trash**: шуточные файлы (old-portfolio-design.zip и т. п.). Если перетащить фото на корзину: «Are you sure? He's nice.»

## Глобальные фичи

- **Кастомный курсор**: белая точка с `mix-blend-mode: difference`, раз в ~4.6 c глитчит (сдвиг + голубая/розовая RGB-копии). Режимы: кольцо над ссылками, большой круг с подписью над спец-элементами (OPEN </>, HELLO, READ CV, → CV, SAVE, ▶ RUN), мигающая каретка над текстом. Плавное следование (lerp). Магнитный эффект у иконок и главных кнопок. На тач-устройствах — отключён.
- **Палитра команд** ⌘K / Ctrl+K: файлы, Summarize, Run, темы, приложения, звук, reboot. Навигация стрелками.
- **Scramble-эффект букв** при наведении на заголовок и имена файлов.
- **Заставка**: через 30 c бездействия на рабочем столе — скачущий логотип; движение мыши будит.
- **Звук** (по умолчанию выключен): короткие клики WebAudio.
- **Пасхалки**: Konami-код (↑↑↓↓←→←→BA, распознавать по `event.code`, чтобы работало на русской раскладке) → 8-битный режим; секрет в консоли браузера (ASCII-логотип + подсказки `sudo make coffee` и Konami).
- **Достижения (17)**: выезжающая панель со списком, прогресс-бар, отметки (хранить в localStorage). Клик по пункту открывает нужный экран и запускает **курсор-гид**: лаймовая стрелка с подписью прилетает к нужному элементу. Список и тексты подсказок — в `questDefs()` в Main.dc.html.

## Мобильная версия

Другая метафора — «телефон». Экран блокировки (свайп вверх) → домашний экран (виджет с фото и статусом, часы, сетка приложений, Dock) → приложения на весь экран: Portfolio (упрощённая IDE: список файлов → файл на весь экран, кнопка → CV), Resume (печать + большая кнопка Download PDF), Terminal (команды кнопками), Messages, Music (Spotify), GitHub, Telegram, Contact. Карточка «There's more on desktop» зовёт открыть сайт с компьютера. Без курсора, drag и хоткеев.

Переключение десктоп/мобилка — по ширине экрана и `(pointer: coarse)`; планшет — на усмотрение.

## Данные

Все тексты свести в один модуль данных (опыт, проекты, навыки, ответы бота, команды терминала, достижения, RU-перевод резюме) и использовать во всех местах: IDE, резюме, терминал, бот, мобилка. Сейчас они продублированы между файлами прототипа — источник правды CV.

## Известные проблемы прототипа (исправить в реализации)

1. Бросок фото в корзину: допуск ~30 px — слишком мало, засчитывать по наведению на Dock/иконку с запасом.
2. Подсветка повторов слов использует CSS Custom Highlight API — нужен fallback.
3. Таймер сна 30 c сбрасывается любым движением — сократить или сделать мягче.
4. Хоткеи (⌘K, Konami) в превью перехватывал редактор — на проде вешать на `window`/`document`.
5. RU-названия «НИИгазэкономика, Центр цифровой информации» и «Автошкола «Единый стандарт»» — **уточнить у Андрея**.
6. Фото — временное, заменить на оригинал.
7. Download PDF — отдавать настоящий файл из `/public`, не `window.print()`.

## Критерии готовности

- Все экраны и фичи из списка выше работают в последних Chrome, Safari, Firefox.
- Мобилка удобна на 360–430 px, все тач-цели ≥ 44 px.
- Тексты совпадают с CV, EN/RU резюме корректно.
- prefers-reduced-motion отключает тяжёлые анимации; всё доступно с клавиатуры, у иконок есть aria-label.
- Первая загрузка быстрая (код окон/приложений можно грузить лениво).
- Деплой на Vercel проходит, старый дизайн удалён.
