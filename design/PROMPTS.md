# Промпты для Claude Code

Распакуй архив в корень репозитория `portfolio_site` (появится папка `design/`), открой терминал в корне и запусти `claude`. Дальше — по шагам. После каждого шага смотри результат локально (`npm run dev`) или на превью-деплое Vercel и коммить.

---

## Шаг 0. Знакомство и план (без кода)

```
Прочитай design/HANDOFF.md и разберись в прототипе: design/Main.dc.html (десктоп) и design/Mobile.dc.html (мобилка) — это исходники интерактивного прототипа из Claude Design, логика в классе Component внизу каждого файла, стили в <helmet><style>. Источник правды для всех текстов — design/Andrey_Dmitriev_CV.pdf.

Задача: полностью заменить текущий дизайн сайта на этот. Ты можешь менять что угодно — структуру, фреймворк, библиотеки, сборку, хоть переписать с нуля, — как считаешь правильным. Обязательно только: деплой на Vercel, тексты строго по CV, поведение и визуал как в прототипе или лучше, хорошая производительность и доступность.

Сначала изучи текущий репозиторий и прототип, потом предложи план: стек, структуру папок, разбиение на компоненты, где будут данные, как разделишь десктоп и мобилку, порядок работ по шагам. Код пока не пиши.
```

## Шаг 1. Фундамент

```
Реализуй фундамент по плану: проект (или миграцию на выбранный стек), шрифты, цветовые токены, глобальные стили, единый модуль данных со всеми текстами из CV (опыт, проекты, навыки, RU-перевод резюме, ответы бота, команды терминала, список достижений), переключение десктоп/мобилка. Старый дизайн убери. Положи CV в public как настоящий PDF для скачивания и заложи /public/photo.jpg.
```

## Шаг 2. Загрузка, экран блокировки, рабочий стол

```
Сделай BIOS-загрузку, экран блокировки и рабочий стол по HANDOFF.md и Main.dc.html: обои, меню, окно с фото, иконки, уведомление, курсор-призрак к иконке IDE, стикер, Dock. Анимации — как в прототипе (keyframes в <helmet>).
```

## Шаг 3. IDE

```
Сделай IDE: анимация открытия из иконки, проводник, вкладки, все файлы с подсветкой синтаксиса, README со scramble-заголовком и бегущей строкой, файлы проектов с git blame при наведении, ▶ RUN с мини-демо, панель Terminal/Problems, статус-бар, 4 темы, подсветка повторов выделенного слова (с fallback).
```

## Шаг 4. Summarize → резюме

```
Сделай переход Summarize: луч сканирования, сжатие окна в лист, «печать» резюме. Резюме — EN/RU с scramble-переключением, кнопка Download PDF отдаёт настоящий файл из public. Проверь, что все тексты совпадают с CV.
```

## Шаг 5. Окна-приложения

```
Сделай оконную систему (drag за заголовок, z-order, открытие/закрытие из Dock) и приложения: Terminal (все команды из HANDOFF.md, Tab-автодополнение, история), Task Manager, Messages/Andrey.bot, Now coding со ссылкой на Spotify, Trash с диалогом при броске фото. Andrey.bot можешь сделать на LLM через API-роут с системным промптом из CV — на твоё усмотрение, но с лимитами и fallback на скриптовые ответы.
```

## Шаг 6. Курсор, палитра, пасхалки, достижения

```
Сделай кастомный курсор (blend difference, периодический глитч, режимы link/text/подписи, lerp, магнитные кнопки, отключение на тач), палитру ⌘K, scramble-эффекты, заставку после бездействия, звук, Konami-код (по event.code) с 8-битным режимом, секрет в консоли, и систему из 17 достижений с панелью, прогрессом в localStorage и курсором-гидом, который прилетает к нужному элементу.
```

## Шаг 7. Мобильная версия

```
Сделай мобильную версию по design/Mobile.dc.html: экран блокировки со свайпом, домашний экран, приложения на весь экран, карточка «There's more on desktop». Тач-цели не меньше 44px, проверь 360–430px.
```

## Шаг 8. Полировка и проверка

```
Пройдись по критериям готовности из HANDOFF.md: кросс-браузерность, prefers-reduced-motion, клавиатура и aria-label, Lighthouse (производительность, доступность, SEO), ленивая загрузка тяжёлых частей, мета-теги и OG-картинка. Исправь «Известные проблемы прототипа». Дай список того, что осталось уточнить у меня.
```

---

### Полезно знать

- Если Claude Code уходит не туда — останови и уточни; лучше маленькими шагами.
- Просить «покажи план/дифф перед изменениями» — нормально.
- Названия на русском (НИИ, автошкола) и фото — уточни/замени сам, они помечены в HANDOFF.md.
